# Security policy

## Reporting a critical bug or vulnerability

Report privately. Do not open a public issue.

- **Email:** support@zeroenclave.com, subject starting with `[SECURITY]`
- **Or:** [GitHub private vulnerability reporting](https://github.com/zeroenclave/zeroenclave/security/advisories/new)

What counts as critical:

- weaknesses in the encryption, key handling or vault format
- plaintext photos, videos, thumbnails or keys on disk, in logs or in backups
- ways to open a vault without the master password, the recovery key or the PIN
- data loss: a vault or backup that no longer opens with the correct password

Please include the app version (Settings → About), device and iOS version, and the steps to reproduce. Never send your password, your recovery key or private photos.

## What happens next

- Confirmation of receipt within 7 days.
- A fix is released before details are published. Credit is given if you want it.

## Supported versions

Only the latest App Store version receives security fixes.
