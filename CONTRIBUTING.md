# Contributing

Thanks for your interest in Zero Enclave.

- **Issues are welcome:** bug reports and feature requests via the [issue templates](https://github.com/zeroenclave/zeroenclave/issues/new/choose).
- **Pull requests are not accepted for now.** They are closed automatically. If you have a fix, describe it in an issue; it will be implemented in the main development line.
- **Security issues:** never in a public issue, see [SECURITY.md](SECURITY.md).

This repository receives one commit per App Store release, matching exactly the code of that build.
